# Прописи C++

Тренажёр для изучения C++ по принципу школьных прописей. Описываешь, что хочешь запрограммировать, и получаешь урок. Код урока показан бледным «карандашом», и ты печатаешь его поверх. Справа на полях заметки объясняют каждую строку: что она делает и как это работает.

## Что внутри

- **Пропись.** Лист в клетку с кодом-образцом. Правильные символы становятся «чернилами» с подсветкой синтаксиса. Ошибка подчёркивается красным, а в строке состояния появляется сообщение в стиле компилятора (`main.cpp:4:12: ошибка: ожидалось «;»…`). Там же подсказка, где этот символ на клавиатуре, и предупреждение о русской раскладке. Отступы ставятся сами.
- **Заметки на полях** к текущей строке. Подсказка по любому слову кода появляется при наведении или по нажатию (`cout`, `<<`, `::`, `\r`…).
- **Пример запуска.** После урока «терминал» показывает, что выведет программа. Анимации проигрываются кадр за кадром.
- **Оценка** за точность («5», «4», «3»), скорость в знаках в минуту и домашнее задание.
- **Уроки.** Курс из 10 уроков: от «Привет, мир!» до игры «Угадай число». Среди них «Движущийся объект» и «Мяч-объект» со `struct`.
- **Правила.** Анатомия программы, инструкции и `;`, блоки, переменные, операторы, ввод и вывод, условия, циклы, функции, массивы, структуры, `std::`, стиль, запуск и разбор ошибок `g++`, словарик.

Код всех готовых уроков проверен компилятором (`g++ -std=c++17 -Wall -Wextra`, без предупреждений). Анимации в примерах запуска совпадают с выводом настоящих программ.

## Как запустить

- **На claude.ai** страница опубликована как артефакт. Там уроки по запросу составляет Claude: страница сама обращается к нему, при первом запросе попросит разрешение. Там же работает кнопка «Спросить учителя».
- **С диска:** открой `index.html` в браузере. Работают готовые уроки, правила и вся проверка набора. Без Claude запрос подбирает похожий готовый урок.

Прогресс и составленные уроки хранятся в `localStorage` браузера.

## Устройство

| Файл | Что в нём |
| --- | --- |
| `index.html` | страница для запуска с диска |
| `src/lessons.js` | готовые уроки: код, заметки по строкам, пример запуска, задания |
| `src/rules.js` | правила, анатомия программы, словарик и подсказки к словам кода |
| `src/app.js` | логика: набор поверх образца, заметки, терминал, обращение к Claude |
| `src/style.css` | оформление: тетрадь в клетку в светлой теме, школьная доска в тёмной |
| `build.mjs` | собирает всё в одну страницу для публикации: `node build.mjs` → `dist/propisi-artifact.html` |

### Как добавить свой урок

Добавь объект в массив в `src/lessons.js`:

```js
{
  id: 'timer',                       // латиница, цифры, дефис
  title: 'Таймер',
  summary: 'Что делает программа.',
  concepts: ['цикл for', 'пауза'],
  keywords: ['таймер', 'секундомер'], // по ним урок подбирается без Claude
  code: String.raw`#include <iostream>
...`,
  notes: [{ from: 1, to: 1, title: 'Библиотека', text: '`<iostream>` — ввод и вывод.', rule: 'io' }],
  run: { kind: 'text', output: 'Вывод программы, ввод пользователя в [[квадратных скобках]]' },
  tasks: ['Что попробовать изменить.']
}
```

В коде урока используй только латиницу и отступы по 4 пробела.
